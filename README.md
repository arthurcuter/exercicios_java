# Exercícios Java

Exercícios em Java que faço enquanto sigo a trilha de estudos de Java, com foco em lógica de programação e orientação a objetos.

## primeira_leva

Lista de exercícios de lógica de programação da [DIO](https://www.dio.me/articles/lista-de-exercicios-para-treinar-logica-de-programacao), resolvida em Java.

- Os enunciados estão em [`EXERCICIOS.md`](primeira_leva/EXERCICIOS.md)
- Cada exercício está em um arquivo próprio: `Exercicio1.java`, `Exercicio2.java` e assim por diante

Treina leitura de dados, condicionais, laços de repetição e operações matemáticas básicas.

## aula70_dev_dojo

Exercício de **associação entre classes** da Maratona Java do DevDojo, em um projeto Maven com Java 21.

Modela um seminário escolar com as classes `Aluno`, `Professor`, `Local` e `Seminario`, mostrando como os objetos se relacionam entre si. A classe `AssociacaoTeste` monta o cenário e imprime os seminários de um professor.

## Como rodar

Abra a pasta do exercício no IntelliJ IDEA e execute a classe com o método `main`.
